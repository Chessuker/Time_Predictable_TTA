## Change from the historical sweep

The historical sweep (fingerprint af6db573b3819269, 53 runs, 2026-10-11)
ran on the memory before the A5-1 fix, which served a new transaction at
BURST_LAT whenever the bus cycle had not dropped since the previous one.
Its results are kept in `build/baseline_poll_sweep/historical_pre_A5-1/`
(not in git) and in the git history of this file.

- c1 (caches on): all 24 runs and both references are unchanged,
  value for value.
- c0 (caches off): every run changed. The interrupt-mode reference fell from
  1281.1 to 1092.7 data units per period, and the L_mip bracket widened from
  (3, 4) to (4, 6).
